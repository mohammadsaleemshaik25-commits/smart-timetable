# Smart Meeting and Exam Timetable Scheduler

An AI-assisted scheduling system designed for college academic departments to generate conflict-free timetables for meetings and exam invigilations.

## Repository Structure

- `frontend/`: React + Vite application with Navy Blue & Light Blue UI theme.
  - Complete forms for schedule parameters, participant management with busy slots, room management with capacity & preferences, and master timetable display (Day, Time, Place, Participants).
  - Ready for future backend API integration (`POST /api/schedule/generate`).

## Running the Application

```bash
cd smart-meeting-exam-scheduler/frontend
npm run dev
```
